# Municipal Reports – NLP Capstone Project
## بلاغات البلدية

### Project Overview
An intelligent municipal report analysis project using Natural Language Processing (NLP) and Transformers.

### Project Components
- Text Preprocessing and Tokenization
- Transformer Architecture and Attention
- Model Fine-tuning and Text Classification
- Arabic NLP and Named Entity Recognition
- Semantic Search and Embeddings
- Model Evaluation and Error Analysis
- Proposed Inference Optimization

### Repository Contents
- Capstone Project Presentation (PowerPoint)
- Practical NLP Labs (Labs 1–6)
